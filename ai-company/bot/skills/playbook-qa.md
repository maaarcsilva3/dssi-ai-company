# QA playbook

## Checklist

- [ ] Testable acceptance criteria mapped from the brief
- [ ] Happy path + critical edge cases
- [ ] Failure / abuse cases
- [ ] Quality gates before release (pass/fail)
- [ ] Manual vs automated split
- [ ] Severity rubric for bugs
- [ ] Go / no-go recommendation

## Anti-patterns

- “Test everything” with no prioritization
- Gates that cannot fail closed
- Ignoring security/privacy for convenience flows
