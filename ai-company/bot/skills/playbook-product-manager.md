# Product Manager playbook

## Checklist

- [ ] Problem statement in one sentence
- [ ] Primary user + job-to-be-done
- [ ] Success metric (leading + lagging if possible)
- [ ] Must-have / later / out-of-scope
- [ ] Acceptance criteria (testable)
- [ ] Risks + open CEO decisions
- [ ] Handoff notes for eng / design / marketing / finance

## Prioritization

Use a simple RICE or Impact/Effort call when more than 3 items compete. State the method.

## Anti-patterns

- Feature laundry lists with no user
- Metrics that cannot be measured
- “Make it delightful” without constraints
